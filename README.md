# Evogym Fitness Website

Evogym is a responsive fitness website built with React and TypeScript. It
showcases the gym's facilities, benefits, classes, and membership contact form
in a focused single-page experience.

## Live Demo

The application is deployed on Vercel and available at
[gym-typescript-k3owpv0zi-obiamakamarias-projects.vercel.app](https://gym-typescript-k3owpv0zi-obiamakamarias-projects.vercel.app/).

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Smooth in-page navigation between site sections
- Animated section transitions powered by Framer Motion
- Fitness benefits and class listings with supporting imagery
- Membership contact form with client-side validation
- Mobile navigation menu

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Hook Form
- Heroicons

## Getting Started

### Prerequisites

- Node.js 16 or newer
- npm

### Installation

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Vite will provide a local URL in the terminal, usually
`http://localhost:5173`.
